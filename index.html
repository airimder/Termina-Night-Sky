Termina Night Sky

In Majora's Mask, the stars over Termina are worked out from the player's name, so every file has its own night sky. Type a name to see yours.

Up to 8 characters: letters, digits, space, . and -, as on the file select screen. Capital letters count, so Link and LINK have different skies.

Stars

How it works

The game turns the 8 characters of the file name into a 32-bit seed by shifting each character code by a different amount and combining them. Unused characters count as spaces. Every frame, it uses that seed to run its random number generator and redraws the stars from scratch. Nothing is stored, which is why the sky can't be pulled out of the game's files.

The first 16 stars are the same on every file, a small blue constellation with one orange star. After that, each star takes four random numbers: two averaged together for height (so most stars sit low near the horizon), one for direction, and one for size. Their colour steps through a pale violet-to-pink list every 64 stars.

Each area asks for a different number of stars, and always draws the first ones from the same list. So the 300 stars over Clock Town and Termina Field are the first 300 of the full 1,500.

On the second night, the rainy one, most of Termina switches to a cloudy night sky and shows no stars at all. Great Bay, the Southern Swamp and the mountains keep theirs.

This page is a direct port of Environment_DrawSkyboxStarsImpl from the Majora's Mask decompilation. The star counts were read from the US version's area data.
